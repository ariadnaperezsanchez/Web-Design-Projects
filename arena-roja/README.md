# 💍 Arena Roja

## About the Project

Arena Roja is an existing e-commerce website where I contributed to visual and design improvements.

Unlike Fumata Negra, I did not build this website from scratch. My work focused on improving and refining parts of the existing website while maintaining its established identity and functionality.

## 👩‍💻 My Role

My contributions included:

- Visual design adjustments
- Layout improvements
- UI refinements
- Content presentation improvements
- Website maintenance
- Design consistency improvements

## 🛠️ Platform & Skills

- Shopify
- E-commerce
- Responsive Web Design
- UI/UX Design

## 🎨 Design Approach

The objective was to improve selected areas of the existing website while respecting its established brand identity and e-commerce structure.

The changes focused on creating a more polished and consistent visual experience.
