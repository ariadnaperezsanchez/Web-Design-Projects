# 🔥 Fumata Negra Asador

## About the Project

Fumata Negra Asador is a restaurant website that I designed and built from scratch using WordPress and Elementor.

The goal was to create a visually attractive and easy-to-navigate website that reflects the identity of the restaurant, presents its gastronomic offering and provides visitors with clear access to relevant information and reservation options.

## 👩‍💻 My Role

I was responsible for the creation of the website from scratch, including:

- Website structure and page layout
- Visual design
- WordPress and Elementor implementation
- Content organization
- Responsive design
- Navigation structure
- Restaurant and menu presentation
- Call-to-action sections
- Reservation-oriented sections
- Visual adjustments and optimization

## 🛠️ Tools & Technologies

- WordPress
- Elementor
- Responsive Web Design
- UI/UX Design

## 🎨 Design Approach

The website was designed to communicate the restaurant's identity through strong visual content while keeping navigation simple and intuitive.

Special attention was given to the presentation of the restaurant, its gastronomic offering, menus and reservation calls to action.
